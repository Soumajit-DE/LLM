# Skills Registry

This file lists reusable prompt skills for this workspace.

## Available Skills

- [create-agent](create-agent.md): Generates a complete Python implementation for any requested agent use case using LangGraph as the core orchestration framework.

## How to Use

In Copilot Chat, ask with a direct instruction such as:

- "Create agent for me for invoice processing"
- "Use create-agent skill for a support chatbot"

The assistant should produce a runnable Python file with full implementation, including:

- LangGraph-based conversation flow
- Knowledge retrieval or FAQ lookup
- Basic guardrails and fallback handling
- Example run section
